# Як підключити синхронізацію (Google Таблиця)

Робиться **один раз** на ноутбуці, приблизно 15 хвилин. Після цього ноутбук і телефон
бачать одне й те саме, а таблиця — ще й резервна копія всіх даних.

Дані лежатимуть у Google-акаунті того, хто виконує ці кроки. Для справжньої роботи —
в акаунті вчительки.

## 1. Створити таблицю

1. Відкрийте **https://sheets.new** (створиться нова Google Таблиця).
2. Назвіть її, наприклад, **«Уроки — дані»**.

## 2. Вставити код

1. У таблиці: меню **Розширення → Apps Script**.
2. У редакторі, що відкрився, виділіть увесь код у файлі `Code.gs` і видаліть його.
3. Відкрийте файл [`backend/Code.gs`](../backend/Code.gs) → кнопка **Copy raw file** (значок копіювання
   праворуч угорі) → вставте в редактор.
4. Натисніть **💾 Зберегти** (Ctrl+S).

## 3. Запустити налаштування

1. Угорі редактора у списку функцій виберіть **`setup`** і натисніть **▶ Виконати**.
2. Google попросить дозвіл: **Переглянути дозволи** → виберіть свій акаунт.
3. З'явиться попередження **«Google не перевірив цей додаток»** — це нормально для власного
   скрипта: **Додатково → Перейти до «…» (небезпечно)** → **Дозволити**.
4. Унизу в журналі з'явиться «Готово. Код доступу: XXXX-XXXX-XXXX-XXXX».
   У таблиці з'являться вкладки «Підключення», «Учні», «Уроки», «Оплати», «Групи».

## 4. Опублікувати

1. Праворуч угорі: **Розгорнути → Нове розгортання**.
2. Біля «Виберіть тип» — шестерня → **Веб-додаток** (Web app).
3. Заповніть:
   - **Виконувати як** (Execute as): **Я** (Me, ваша пошта)
   - **Хто має доступ** (Who has access): **Будь-хто** (Anyone) — саме цей варіант, не «Будь-хто з
     обліковим записом Google». Без коду доступу ніхто нічого не отримає.
4. **Розгорнути** (Deploy) → скопіюйте **URL веб-додатка** (закінчується на `/exec`).

Назви пунктів у меню Google можуть трохи відрізнятися — в дужках англійський варіант.

## 5. Підключити ноутбук

1. Відкрийте застосунок → **Ще → Синхронізація**.
2. Вставте в поле адресу (`…/exec`) і код доступу з вкладки «Підключення» — можна разом.
3. **Перевірити** → виберіть, що робити з даними:
   - **Відправити мої дані в таблицю** — якщо на ноутбуці вже щось внесено;
   - **Почати з чистого аркуша** — якщо там лише демо-учні.

Після першого підключення на вкладці «Підключення» в таблиці з'явиться готовий
**«Код для іншого пристрою»**.

## 6. Підключити телефон

1. На телефоні відкрийте застосунок з іконки на початковому екрані → **Ще → Синхронізація**.
2. Відкрийте програму **Google Таблиці** → «Уроки — дані» → вкладка «Підключення» →
   скопіюйте клітинку з кодом для іншого пристрою.
3. Вставте в застосунок → **Перевірити → Завантажити дані з таблиці**.

Готово. Хмаринка вгорі календаря показує стан: ☁ — усе збережено, ↻ — синхронізується,
крапка — є зміни, які ще не відправлені (наприклад, без інтернету).

## Якщо щось не так

| Повідомлення | Що зробити |
|---|---|
| «Адреса не відповідає…» | У розгортанні «Хто має доступ» має бути **Будь-хто** (Anyone). Розгорнути → Керувати розгортаннями → ✏ → змінити доступ. |
| «Невірний код доступу» | Скопіюйте код з вкладки «Підключення» ще раз. |
| «У таблиці ще не запущено setup» | Виконайте крок 3. |

## Оновлення коду (коли змінюється `Code.gs`)

1. Вставте новий код у редактор Apps Script → Зберегти.
2. **Розгорнути → Керувати розгортаннями** → ✏ (редагувати) → **Версія: Нова версія** → **Розгорнути**.

Адреса `/exec` при цьому не змінюється, перепідключати пристрої не треба.

## Якщо код доступу потрапив до чужих

У таблиці: меню **Уроки → Змінити код доступу**. Потім на кожному пристрої:
Ще → Синхронізація → Відключити → підключити з новим кодом.

## Перевірка без Google (для розробки)

```bash
node backend/dev/mock-server.mjs
```

Запускає той самий `Code.gs` локально з таблицею в пам'яті: адреса `http://localhost:8787/exec`,
код доступу друкується в консолі.
