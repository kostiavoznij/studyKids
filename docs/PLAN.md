# План: застосунок «Уроки» для репетиторки

## Для кого і навіщо

Репетиторка української мови для дітей, уроки онлайн, індивідуальні (групи — у перспективі).
Учні з України та з-за кордону, кілька вчать українську як іноземну. Зараз усе ведеться
рядками в Google Календарі («Варя (читання)», по 1 год, ~6 уроків на день) — без деталей,
історії та підрахунку грошей.

Пристрої: iPhone + ПК на Windows, браузер Google Chrome на обох.

## Вимоги

- **Календар — головний екран**: день / тиждень / місяць, кольори учнів, статуси уроків.
- **Гроші — лише гривні** (навіть коли батьки за кордоном). Ціна своя в кожного учня, можна змінити на уроці.
  Суми за день, тиждень, місяць.
- **Оплати**: здебільшого **наперед пакетом** на кілька уроків — застосунок веде рахунок учня
  (скільки уроків ще оплачено) і попереджає, коли оплачені уроки закінчуються. Частина батьків
  платить **після кожного уроку** — кнопка «Оплатили» в картці уроку.
- **Урок**: тема, ДЗ, нотатки, оцінка засвоєння.
- **Пробні уроки**: безкоштовне знайомство з новим учнем; звіт — рівень, сильні сторони, що
  підтягнути, план, результат (продовжуємо / думають / не продовжили). Окремо в розкладі й статистиці.
- **Скасування й перенесення** — часті, тому це окремі швидкі дії з історією (хто, чому, звідки → куди).
- **Постійний розклад** учня (напр. «вт 17:00») — уроки створюються автоматично наперед.
- **Сторінка кожного учня**: прогрес, історія уроків і тем, оплати, звіт пробного уроку, нотатки.
- **Статистика**: дохід за уроки й надходження оплат, передоплати й борги, пробні → нові учні,
  що просіло / покращилось. Рахується з моменту початку користування (історію з календаря НЕ імпортуємо).
- **Групи** (у перспективі): урок з кількома учнями, але індивідуальний лишається найпростішим сценарієм.
- **Теми оформлення**: світла, темна, чорна та ще кілька.
- **Гарний візуал і зручність** — користуватиметься щодня з телефона.

## Архітектура

```
iPhone / ПК (PWA, іконка на екрані)
        │
        ▼
PWA на GitHub Pages  ── React + Vite + TypeScript, service worker, офлайн-кеш
        │  POST text/plain + секретний ключ
        ▼
Google Apps Script (API, її акаунт)
   ├── Google Таблиця — база даних
   └── Google Календар — дублювання подій для нагадувань
```

- Секретний ключ і адреса API вводяться один раз на пристрої, у коді їх немає (репозиторій публічний).
- Дані на пристрої — копія для швидкості й офлайну; головна копія — у Таблиці.
- Розробка й тести — на тестовому акаунті з вигаданими даними; на її акаунт переносимо в кінці.

## Модель даних

- **Student**: ім'я, колір, предмет, клас/вік, ціна, як платять (наперед / після уроку), тривалість,
  часовий пояс, контакти, постійний розклад, статус (займається / пробний / пауза / архів), нотатки.
- **Group**: назва, учні, розклад, ціна з учня.
- **Lesson**: початок, тривалість, тип (звичайний / пробний), учасники (ціна, оцінка, відсутність),
  статус (planned / done / cancelled), тема, ДЗ, нотатка, звіт пробного уроку, скасування,
  історія перенесень, `slotKey` для згенерованих з розкладу (він же id — однаковий на всіх пристроях).
- **Payment**: учень, дата, сума, на скільки уроків. Проведені уроки списують оплати по черзі —
  звідси «оплачено ще N уроків» або борг.
- Усі записи мають `id`, `updatedAt`, м'яке видалення `deletedAt` — під синхронізацію.

## Синхронізація

`backend/Code.gs` у Google Таблиці: `push` (новіший `updatedAt` перемагає) і `pull` (усе, що
змінилось після останньої ревізії). Інструкція — [SYNC_SETUP.md](SYNC_SETUP.md).
Локальна перевірка без Google — `node backend/dev/mock-server.mjs`.

## Етапи

1. ✅ Прототип інтерфейсу з демо-даними → GitHub Pages.
2. ✅ Оплати пакетами, пробні уроки, лише гривні.
3. ✅ Синхронізація через Google Таблицю (код готовий; підключення — на тестовому акаунті, потім на її).
4. Дублювання уроків у Google Календар з нагадуваннями.
5. Доведення статистики та сторінок учнів за її відгуками.
