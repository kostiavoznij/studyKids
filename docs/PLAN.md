# План: застосунок «Уроки» для репетиторки

## Для кого і навіщо

Репетиторка української мови для дітей, уроки онлайн, індивідуальні (групи — у перспективі).
Учні з України та з-за кордону, кілька вчать українську як іноземну. Зараз усе ведеться
рядками в Google Календарі («Варя (читання)», по 1 год, ~6 уроків на день) — без деталей,
історії та підрахунку грошей.

Пристрої: iPhone + ПК на Windows, браузер Google Chrome на обох.

## Вимоги

- **Календар — головний екран**: день / тиждень / місяць, кольори учнів, статуси уроків.
- **Гроші**: вартість заняття (своя в кожного учня, можна змінити на конкретному уроці),
  суми за день, тиждень, місяць; учні платять у різних валютах.
- **Урок**: тема, ДЗ, нотатки, оцінка засвоєння, оплачено/ні.
- **Скасування й перенесення** — часті, тому це окремі швидкі дії з історією (хто, чому, звідки → куди).
- **Постійний розклад** учня (напр. «вт 17:00») — уроки створюються автоматично наперед.
- **Сторінка кожного учня**: прогрес, історія уроків і тем, скільки тем/уроків/грошей,
  скасування й перенесення, нотатки.
- **Статистика**: що просіло, що покращилось, порівняння з минулим періодом, рейтинг учнів.
  Рахується з моменту початку користування (історію з календаря НЕ імпортуємо).
- **Групи** (у перспективі): урок з кількома учнями, але індивідуальний урок лишається
  найпростішим сценарієм.
- **Теми оформлення**: світла, темна, чорна та ще кілька — перемикач у налаштуваннях.
- **Гарний візуал і зручність** — користуватиметься щодня з телефона.

## Архітектура

```
iPhone / ПК (PWA, іконка на екрані)
        │
        ▼
PWA на GitHub Pages  ── React + Vite + TypeScript, service worker, офлайн-кеш
        │  POST text/plain + секретний ключ
        ▼
Google Apps Script (API, її акаунт)
   ├── Google Таблиця — база даних
   └── Google Календар — дублювання подій для нагадувань
```

- Секретний ключ і адреса API вводяться один раз на пристрої, у коді їх немає (репозиторій публічний).
- Дані на пристрої — копія для швидкості й офлайну; головна копія — у Таблиці.
- Розробка й тести — на тестовому акаунті з вигаданими даними; на її акаунт переносимо в кінці.

## Модель даних

- **Student**: ім'я, колір, предмет, клас/вік, ціна + валюта, тривалість, часовий пояс,
  контакти, постійний розклад (слоти), статус (активний/пауза/архів), нотатки про прогрес.
- **Group**: назва, учні, розклад, ціна з учня.
- **Lesson**: початок, тривалість, учасники (ціна, валюта, оплачено, оцінка, відсутність),
  статус (planned / done / cancelled), тема, ДЗ, нотатка, скасування (хто, причина,
  чи оплачується), історія перенесень, `slotKey` для згенерованих з розкладу.
- Усі записи мають `id`, `updatedAt`, м'яке видалення `deletedAt` — під синхронізацію.

## Етапи

1. **Прототип інтерфейсу з демо-даними** (без бекенду) → GitHub Pages → вона пробує на iPhone. ← зараз
2. Бекенд на Apps Script + Таблиця (тестовий акаунт).
3. Синхронізація, офлайн-черга змін.
4. Дублювання уроків у Google Календар з нагадуваннями.
5. Доведення статистики та сторінок учнів за її відгуками.
6. Перенесення на її акаунт, встановлення на iPhone і ПК.

## Відкриті питання

- Учні з-за кордону платять у валюті чи в гривнях? (зараз: валюта в кожного учня своя, курс задається вручну)
- Назва застосунку (робоча — «Уроки»).
