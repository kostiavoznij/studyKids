# Telegram-бот

Бот надсилає батькам повідомлення про уроки. Бот не може написати людині першим, тому кожен учень має
особисте посилання `t.me/<бот>?start=<код>`. Батьки (або старший учень) відкривають його й натискають «Почати»,
і з цієї миті чат прив'язаний до учня. Підключитися можуть обоє батьків, а одні батьки — для кожної своєї дитини.
Хто не має Telegram чи не хоче бота, просто не підключається: усе інше працює як раніше.

|---|---|

| `uroky` (`cecjmzwrrcerltreifsu`) | справжній, `@lastivka_uroky_bot` («Ластівка · уроки української») |

Два різні боти, щоб перевірки ніколи не дійшли до справжніх батьків.

## Як влаштовано

- `supabase/migrations/20261106120000_bot.sql` — таблиці `bot_invites` (код посилання кожного учня) і `bot_chats`
  (хто підключився: чат, ім'я з Telegram, чи заблокував бота). Застосунок не читає їх напряму: адміністратор і
  менеджер — через `bot_invite()`, `bot_chats_list()`, `bot_unlink()`; функція-вебхук — через `bot_link()`,
  `bot_stop()`, `bot_blocked()`, доступні лише сервісному ключу.
- `supabase/functions/telegram` — вебхук: сюди Telegram надсилає кожне повідомлення боту. Перевіряє секретний
  заголовок, що це справді Telegram. «Почати» з кодом прив'язує чат, `/stop` відв'язує.
- `supabase/functions/bot` — для застосунку: `status` (адміністратор і менеджер) і `setup` (адміністратор:
  вказує Telegram адресу вебхука, команди й опис бота українською). Хто кличе, перевіряє база (`my_role()`).
- Токен бота — лише в секретах функцій (`TELEGRAM_BOT_TOKEN`), ніколи в базі, коді чи застосунку. Секрет вебхука
  виводиться з токена, тож налаштовувати його окремо не треба.
- У застосунку: Налаштування → Telegram-бот (з'являється, щойно на сервері є токен), картка учня → «Запросити в бот».

## Повідомлення (крок 2)

- Шаблони — записи типу `botTemplates` (синхронізуються, як учні й уроки; менеджер теж їх бачить і змінює).
  Вбудовані `cancel` («Урок скасовано») і `cancelMany` («Кілька днів без уроків») існують як записи лише після
  зміни, до того діє стандартний текст (`app/src/data/botText.ts`). Власні шаблони — `kind: 'free'`.
- Підстановки: {ім'я}, {дата} («сьогодні», «завтра», «у середу, 5 листопада»), {час} (для учнів в іншому часовому
  поясі — «16:00 за Києвом (у вас 15:00)»), {період}, {уроки}, {причина}, {вчителька}. Порожня підстановка не
  лишає «()» чи подвійних пробілів, на початку речення — з великої літери.
- «Повідомити батьків?» з'являється лише коли бот працює і хоч одна сім'я з тих, кого це стосується, його має:
  після скасування уроку вчителькою (урок ще попереду) і після позначки вихідного / лікарняного з уроками попереду.
  «Не надсилати» — один дотик, скасування від цього не залежить.
- «Написати батькам» — картка учня → «Бот підключено» → «Написати батькам», зі своїми шаблонами.
- Надсилає функція `bot` (`action: 'send'`): тексти пише застосунок, функція доставляє в кожен підключений чат
  учня і записує кожну спробу в `bot_messages` (`bot_log()` з правами того, хто надсилав). Заблокований чат
  позначається й більше не отримує.
- Коли не всі отримали — картка «Надіслано N з M» з іменами тих, хто без бота чи до кого не дійшло; дотик по імені
  копіює їхній текст. Закривається хрестиком, нічого робити не треба.

## Налаштування (для кожного проєкту один раз)

1. **Бот.** У Telegram: @BotFather → `/newbot` → назва й адреса (має закінчуватися на `bot`). BotFather видасть
   токен. Нікому його не пересилайте і не вставляйте в чат з Claude.
2. **Токен на сервер.** Supabase → проєкт → Edge Functions → Secrets → Add new secret:
   ім'я `TELEGRAM_BOT_TOKEN`, значення — токен.
3. **Схема й функції** (з кореня репозиторію; `<ref>` — з таблиці вище):
   ```
   npx supabase@3.0.0 db push --remote=<ref> --yes
   npx supabase@3.0.0 functions deploy telegram bot --remote=<ref> --use-api --no-verify-jwt --yes
   ```
   Після змін у функціях — те саме `functions deploy`; після нової міграції — `db push`.

## Перевірка

- Налаштування → Telegram-бот: «@бот працює».
- Картка учня → «Запросити в бот» → «Лише посилання» → відкрити посилання у своєму Telegram → «Почати»:
  бот вітається з іменем учня, у картці (кнопка «Оновити») з'являється ваше ім'я з Telegram.
- `/stop` у боті → картка знову «Ще ніхто не підключився»; повторне «Почати» з тим самим посиланням підключає знову.
- «Нове посилання» → старе посилання відповідає «Це посилання вже не діє».
- Логи функцій: Supabase → Edge Functions → `telegram` / `bot` → Logs.
